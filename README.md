# 💉 Child Vaccination Management System

A simple **Flask-based web application** designed to register children, manage vaccination schedules, and track vaccination completion records.  
It uses an **SQLite database** to store information about children, vaccines, and vaccination history.

---

## 🚀 Features

### 👶 Child Registration
- Register new children with basic details (Name, Date of Birth, Guardian’s Name, Contact).

### 📅 Vaccination Schedule
- Automatically generates vaccination records for each registered child.
- Displays all vaccines assigned to a specific child.

### ✅ Status Tracking
- Update vaccination status (e.g., mark as “Completed”).
- Record actual vaccination dates.

### 📊 Dashboard
- View a list of all registered children.
- Navigate to each child’s vaccination schedule.
